# คนดีศรีท่าหลวง (ทำดีมีเกียรติ)

ระบบจัดเก็บผลงานผู้เรียนด้านคุณธรรม จริยธรรม และจิตอาสา  
**วิทยาลัยเทคนิคท่าหลวงซิเมนต์ไทยอนุสรณ์**

- เว็บแอปหน้าเดียว (SPA) รองรับมือถือ แท็บเล็ต คอมพิวเตอร์ ทั้งแนวตั้งและแนวนอน
- ฟอนต์ Kanit + Sarabun ขนาดใหญ่ อ่านง่าย โทนสีวิทยาลัย (แดงเลือดหมู / น้ำเงินกรมท่า / ทอง)
- ฐานข้อมูล **Google Sheets** ผ่าน Google Apps Script, รูปหลักฐานเก็บใน Google Drive
- อัปเดต **เรียลไทม์** (ตรวจสอบข้อมูลใหม่ทุก 10 วินาที ทุกหน้าจอรีเฟรชเอง)
- อัปโหลดขึ้น **GitHub อัตโนมัติ** และเผยแพร่ผ่าน GitHub Pages

## ฟังก์ชันตามบทบาท

| บทบาท | ทำอะไรได้ |
|---|---|
| บุคคลทั่วไป | ทำเนียบคนดี, สถิติ, Top 5, ฟีดความดี (กรองตาม 9 แผนกวิชา), ตรวจสอบเกียรติบัตรด้วยรหัส/QR Code |
| นักเรียน/นักศึกษา | สมัครสมาชิก, รายงานความดีพร้อมรูป, ติดตามสถานะ, แก้ไขรายการที่ถูกส่งกลับ, แถบความคืบหน้าเหรียญ, พิมพ์เกียรติบัตรและ E-Portfolio (PDF) |
| ครู | ค้นหา/กรองนักศึกษาในที่ปรึกษา, มอบแต้มทันที, เห็นเหรียญปัจจุบันและแจ้งเตือนเมื่อปลดล็อกเหรียญใหม่, พิมพ์เกียรติบัตรให้นักศึกษา |
| ผู้ดูแลระบบ/ผู้บริหาร | อนุมัติ/ส่งกลับแก้ไข, ค้นหาและกรอง, ส่งออก Excel (CSV) และรายงาน PDF, Executive Dashboard (KPI, กราฟแท่ง 9 แผนก, กราฟวงกลมหมวดหมู่), จัดการผู้ใช้ |

เกณฑ์คะแนน: สร้างชื่อเสียง +3 · ซื่อสัตย์ +2 · จิตอาสา +2 · กตัญญู/ช่วยเหลือ +1 · วินัย/สิ่งแวดล้อม +1  
เกียรติบัตร: **ทองแดง 40 แต้ม · เงิน 60 แต้ม · ทอง (คนดีศรีท่าหลวง) 80 แต้ม** (ปรับได้ที่ ผู้ดูแลระบบ → ตั้งค่าระบบ)

## ฟีเจอร์เพิ่มเติม (เวอร์ชัน 2)

- **ตั้งค่าระบบ** (ผู้ดูแลระบบ → ตั้งค่าระบบ): เพิ่ม/แก้ไข/ลบ **แผนกวิชา**, ปรับ **เกณฑ์แต้มเหรียญ**
- **ครูที่ปรึกษา**: เพิ่มทีละคน หรือนำเข้าจากไฟล์ แสดงจำนวนนักศึกษาในที่ปรึกษาของครูแต่ละคน
- **นำเข้ารายชื่อนักเรียน/ครู** จาก Excel (.xlsx) / CSV หรือวางจาก Excel — มีปุ่มดาวน์โหลดแบบฟอร์ม
  คอลัมน์: รหัสนักศึกษา | ชื่อ-นามสกุล | แผนกวิชา | ระดับชั้น | ครูที่ปรึกษา (รหัสหรือชื่อ) | รหัสผ่าน (เว้นว่าง = ใช้รหัสนักศึกษา)
  แผนกวิชาที่ยังไม่มีในระบบจะถูกเพิ่มให้อัตโนมัติ
- **QR Code เข้าสู่ระบบ**: นักศึกษาทุกคนมี QR ประจำตัว (ดูได้ที่ "บัตร QR ของฉัน") สแกนด้วยกล้องมือถือหรือปุ่ม "สแกน QR" แล้วเข้าระบบทันที
  ครู/ผู้ดูแลพิมพ์ **บัตร QR** ได้ทีละหลายคน (10 ใบต่อ A4) และ **ยกเลิก QR เดิม/ออกใหม่** ได้เมื่อบัตรหาย
  ครูสแกน QR บัตรนักศึกษาเพื่อเลือกนักศึกษาตอนมอบแต้มได้ด้วย
- **เกียรติบัตร**: เลือก 4 เทมเพลต (คลาสสิก / ราชพฤกษ์ / โมเดิร์น / ลายไทยประยุกต์) แก้ไขข้อความทุกบรรทัดได้ พร้อมตัวอย่างสด
  **ลงนามโดยผู้อำนวยการท่านเดียว** พร้อม **ลายเซ็นอัตโนมัติ** (อัปโหลดรูป PNG หรือเซ็นบนหน้าจอ) และตราประทับเหรียญตามระดับ
- ไอคอนแบบเส้น (SVG) ทันสมัย แทนอีโมจิทั้งหมด

## 1) เชื่อมต่อ Google Sheets

### แบบอัตโนมัติ (แนะนำ)

1. เปิด Google Apps Script API: https://script.google.com/home/usersettings → **On**
2. ดับเบิลคลิก **`connect-sheets.cmd`** (หรือรัน `node tools/connect-sheets.mjs`)
   - ล็อกอิน Google ครั้งแรก → สร้าง Google Sheets + Apps Script → อัปโหลดโค้ด → Deploy เว็บแอป
   - ใส่ `API_URL` ใน `js/config.js` และอัปโหลดขึ้น GitHub ให้เอง
3. เปิดลิงก์ Apps Script ที่แสดงตอนจบ → เลือกฟังก์ชัน **`setup`** → **Run** → อนุญาตสิทธิ์ (ทำครั้งเดียว)

เมื่อแก้โค้ดภายหลัง ให้รันซ้ำได้เลย ระบบจะอัปเดตเวอร์ชันเดิม URL ไม่เปลี่ยน

### แบบทำเอง (~5 นาที)

1. สร้าง Google Sheets ใหม่ ตั้งชื่อเช่น `คนดีศรีท่าหลวง-ฐานข้อมูล`
2. เมนู **ส่วนขยาย → Apps Script** ลบโค้ดเดิม แล้ววางเนื้อหาทั้งหมดจากไฟล์ [`apps-script/Code.gs`](apps-script/Code.gs) → บันทึก
3. เลือกฟังก์ชัน **`setup`** แล้วกด **เรียกใช้ (Run)** → อนุญาตสิทธิ์ (Sheets + Drive)  
   ระบบจะสร้างชีต `Users`, `Deeds`, `Settings`, โฟลเดอร์รูปใน Drive และบัญชี **admin / admin1234**
4. กด **การทำให้ใช้งานได้ (Deploy) → การทำให้ใช้งานได้รายการใหม่ → เว็บแอป**
   - ดำเนินการในฐานะ: **ฉัน (Me)**
   - ผู้ที่มีสิทธิ์เข้าถึง: **ทุกคน (Anyone)**
5. คัดลอก URL ที่ลงท้ายด้วย `/exec` ไปใส่ในไฟล์ [`js/config.js`](js/config.js) ที่ `API_URL: '...'`
6. บันทึกไฟล์ → ระบบอัปโหลดขึ้น GitHub อัตโนมัติ (ข้อ 2) → เปิดเว็บ ใช้งานได้ทันที
7. เข้าสู่ระบบด้วย admin แล้ว **เปลี่ยนรหัสผ่าน** และเพิ่มบัญชีครูที่เมนู “จัดการผู้ใช้”

> ถ้าแก้ไข `js/core.js` (เช่นชื่อแผนกวิชา) ให้คัดลอก `apps-script/Code.gs` ใหม่ไปวาง แล้ว Deploy → จัดการการทำให้ใช้งานได้ → แก้ไข → เวอร์ชันใหม่

ถ้ายังไม่ใส่ `API_URL` ระบบจะทำงานใน **โหมดสาธิต** (ข้อมูลเก็บในเบราว์เซอร์) บัญชีทดลอง: `66001/1234`, `T001/1234`, `admin/admin1234`

## 2) อัปโหลดขึ้น GitHub อัตโนมัติ

ต้องมี Node.js และล็อกอิน GitHub CLI (`gh auth login`) — ไม่ต้องติดตั้ง git

- ดับเบิลคลิก **`auto-sync.cmd`** → ทุกครั้งที่บันทึกไฟล์ ระบบจะอัปโหลดขึ้น GitHub ภายในไม่กี่วินาที
- หรือรันครั้งเดียว: `node tools/github-sync.mjs`
- ตั้งชื่อ repository ได้ที่ `tools/sync.config.json`
- เว็บไซต์: `https://<ชื่อบัญชี>.github.io/TLDee/`

## โครงสร้างไฟล์

```
index.html              หน้าเว็บหลัก
css/style.css           ดีไซน์ / Responsive / รูปแบบเกียรติบัตรสำหรับพิมพ์
js/config.js            ตั้งค่า API_URL, ชื่อผู้อำนวยการ
js/core.js              ตรรกะหลัก (ใช้ร่วมกันทั้งเว็บและ Apps Script)
js/api.js               ชั้นเชื่อมต่อข้อมูล (Google Sheets / โหมดสาธิต)
js/ui.js                ไอคอน SVG / เหรียญ / ตราประทับ / แม่แบบเกียรติบัตร
js/app.js               หน้าจอทั้งหมด
apps-script/Code.gs     โค้ดสำหรับวางใน Google Apps Script (สร้างอัตโนมัติ)
tools/github-sync.mjs   อัปโหลด GitHub อัตโนมัติ
```
